# Мягкие исправления расчётов и отображения

Этот набор изменений использует уже разделённые слои подготовки, оценки и
отображения. Отдельного режима совместимости или второй логики выбора цвета нет.
Постоянный контракт сценариев — [test-cases.md](test-cases.md).

## Что изменено

- `infrastructure/config`: YAML разбирается с привязкой к странице и правилу.
  Ошибки синтаксиса, формы настроек и привязок возвращаются как данные.
  Корректные независимые правила продолжают работать. Даты в фильтрах остаются
  токенами до расчёта очередного обновления.
- `domain/utils` и `domain/services`: пустые и непригодные значения не становятся
  нулями. Формулы используют исходную точность. Пороги внутри метрики по-прежнему
  применяются последовательно; между результатами выигрывает больший `lvl`, при
  равенстве — первый в конфиге. Явный `lvl: 0` сохраняется.
- Таблица выбирает точную колонку либо единственный подходящий префикс. Число,
  уровень и цвет победителя принадлежат одной строке; форматированный текст
  хранится отдельно. Таблица без `thresholdKey` остаётся доступной для чтения,
  но не получает фиктивный числовой результат.
- `application`: результат содержит расчёты и список диагностик с источниками
  и известными SVG IDs. Номер обновления не даёт старой асинхронной работе
  заменить новую. При загрузке прежний вид сопровождается «Обновляется…»;
  завершившаяся ошибка не публикует старые series как успешный текущий результат.
- `presentation`: при частичной потере данных сохраняется цвет доступных метрик.
  Если числового результата нет, динамический индикатор серый с сохранением
  способа окраски (`fill`/`stroke`/`none`). Разрешённый tooltip показывает причины,
  в том числе при no-data; открытая и закреплённая подсказки обновляются.
- SVG-адаптер восстанавливает исходные атрибуты, их отсутствие, inline styles,
  подписи и ссылки. Очистка вложенных IDs не отменяет текущую окраску группы.
  Grid получает цвет окончательного победителя.

Условия используют правую границу панели и собственное фиксированное смещение
(`timezone`, по умолчанию UTC+3). Час, минута и день недели относятся к одному
моменту. `$date` и `$date-1` используют UTC-день той же границы: live-просмотр
сохраняет привычное поведение, история перестаёт зависеть от сегодняшней даты.

## Что не добавлено

Нет модалки, общего списка ошибок в UI или нового API.
Ошибки конфигурации уже есть в результате расчёта, но
нового интерфейса для них нет. В tooltip выводятся причины отсутствия данных,
ошибки вычислений/условий и выбора табличного поля; запрет tooltip сохраняется.
Отбор grid/notify по уровню, отдельный числовой порог notify и отсутствие таблиц
в notify не переопределяются.

`autoConfig` остаётся позиционным. Известное поле с пустым результатом сохраняет
место; при полном исчезновении query прежние тип и количество рядов неизвестны.
Последующие назначения могут сдвинуться — это явно зафиксированное ограничение
C28, а не исправленный сценарий. Сохранение распределения между обновлениями
требует отдельного решения.

## Сравнение с исходной точкой

Исходная точка — `35c2db0`, первый рефакторинг слоёв, 9 исходных Jest-тестов
проходили. Для основных исправлений целевые тесты запускались до изменения
соответствующего кода и после него. Весь новый набор на baseline целиком не
запускался: часть тестов использует новый контракт диагностики.

| Сценарии | Раньше | Сейчас |
| --- | --- | --- |
| L03, L05–L07 | Нулевой уровень терялся; при равенстве влияли число или тип результата | Явный ноль и стабильный порядок |
| B01, B05, B07, B09 | Цвет/уровень из разных строк, первый префикс, display вместо raw | Согласованный winner и однозначная колонка |
| E01, D02, D04 | Округление до формулы; отсутствующие данные могли стать нулём | Исходная точность и явная причина отсутствия |
| E03, T01–T02 | Truthy вместо boolean; текущее время и разные календарные дни | Boolean и единая правая граница |
| T05–T10 | Дата разрешалась при подготовке от реальных часов | Дата разрешается при обновлении от выбранного дня |
| U01, U05, G01–G03 | Пустая/устаревшая подсказка; запоздалое обновление могло победить | Актуальные причины и защита поколением |
| U07–U10 | Оформление залипало, grid мог сохранить промежуточный цвет | Восстановление исходного и окончательный цвет |

Сохранённое поведение также проверяется: последние совпавшие пороги и два
нормальных диапазона, настоящий ноль, schemas, anchors, query-приоритет,
правила grid/notify, отключённые tooltip. Дополнительные регрессионные тесты
закрывают найденные при ревью сочетания: таблица перед числом в tooltip,
непригодный filter/filling рядом с исправным правилом и вложенные SVG IDs.

## Проверки

- Jest: 15 suites, 120 тестов. Каталог содержит 93 сценария; C28 проверяет
  ограничение. Это не 93 отдельных test-функции: часть сценариев параметризована
  или проверяется интеграционно вместе.
- `npm run typecheck` и production `npm run build` проходят.
- `npm run lint`: 0 ошибок; 4 предупреждения deprecated API (`act` в тестах
  React 18.2 и совместимое чтение `PanelData.error`).
- Тесты времени дополнительно проходят с `TZ=Pacific/Honolulu` (49 тестов).

Для повторной проверки используются `npm run test:ci`, `npm run typecheck`,
`npm run lint` и `npm run build`.
